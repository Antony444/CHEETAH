Note: This project is optimized for mobile devices. Please open it on a mobile device or use your browser's developer tools to simulate a mobile view for the best experience.

here is how to open the developer tools to simulate a mobile view
🔹 Google Chrome:
Right-click anywhere on the page and select "Inspect" or press Ctrl+Shift+I (Cmd+Option+I on Mac).

Click the "Toggle Device Toolbar" icon (📱) in the top-left of the DevTools panel, or press Ctrl+Shift+M (Cmd+Shift+M on Mac).

Choose a mobile device from the dropdown menu (e.g., iPhone, Pixel).

Refresh the page if needed.

🔹 Mozilla Firefox:
Right-click on the page and choose "Inspect" or press Ctrl+Shift+I (Cmd+Option+I on Mac).

Click the "Toggle Responsive Design Mode" icon (📱) in the DevTools toolbar or press Ctrl+Shift+M (Cmd+Shift+M on Mac).

Select a mobile device or set a custom resolution.

Refresh the page if needed.
